# thriai.io

Marketing site for Thriai LLC. Astro 5, static output, deployed to GitHub Pages via `.github/workflows/pages.yml` on every push to `main`. Custom domain via `public/CNAME`.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
```

Content source of truth: `Projects/personal/firm/PLAN.md` and `CONCEPT.md` (positioning, tiers, pricing). Entity record: Obsidian vault `Pythia/Thriai LLC/Thriai LLC.md`.

Rules: never use "accounting", "accountant", "audit", or "CPA" to describe the firm or its services. Published pricing is a deliberate differentiator; keep it current.
